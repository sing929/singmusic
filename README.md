# Sing Studio · v1.4.0

本机 YuE2 整首音乐改编工作室。批量导入音频、可选歌词、A/B 完整版本、原唱保留、收藏和可恢复移除。音频、歌词及推理留在电脑上。

这次更新加入“换成原唱音色”：版本生成后，在本机把新歌声换成原曲演唱者的音色。上一版加入的每首 1–10 个版本，以及变调与变速（含 Slowed / Sped up 与可选混响）继续可用。

## 使用换成原唱音色

- **作用**：YuE2 生成新版本后，先用 UVR 分离新歌声与新伴奏，再用本机 Seed-VC 把新歌声换成原曲演唱者的音色，最后重新混音。旋律、歌词、节奏来自新的演唱，只换音色。目标音色取自你导入的原曲（UVR 分离出的原唱），不需要另外录音或训练。
- **设置**：统一设置的“换成原唱音色”面板里按版本（A–J，数量随“每首版本数量”）分别勾选；逐首“单独调整”里可跟随统一或单独设置这首歌。**音域**默认“自动匹配原唱音域”：新歌声与原唱相差较大时整八度移动（例如女声旋律换成男声原唱时降八度），调性不变；也可固定保持、升八度或降八度。
- **范围**：只对“全新演绎”的有演唱歌曲生效；保留原唱已经使用原录音、纯音乐没有歌声，均不换声。原曲变调变速时，目标音色取自未调整的原唱。只在生成前设置，已完成作品不提供换声再处理。
- **名称与信息**：作品名附 `Original Voice`，例如 `Lo-fi Justin Bieber - Baby (Original Voice)`。作品卡片与“参数与歌词”显示八度、乐句数、Seed-VC 步数，以及换声前后与原唱的音色相似度（客观参考，不等于听感）。任务目录保留换声前的 `generated.wav` 以便对比。
- **时间**：每个换声版本另加一次 UVR 分离和换声（首次另需原曲分离），处理时间会增加；应用电脑上的实际用时由 `benchmark_voice.py` 记录，尚未实测。生成偏好“速度优先 / 均衡 / 质量优先”对应 Seed-VC 15 / 30 / 50 步。
- **安装**：换声引擎不随应用附带，需要按 `HANDOFF.md` 先在联网电脑下载安装包、再在应用电脑离线安装；未安装时面板显示“换声引擎未安装”，选项不可用。
- 请只对你拥有权利或已获授权的声音换声。换声可能带来咬字、气声或分离残留问题，请试听复核。

## 每首多个版本

- 在统一设置的“每首版本数量”选择 1–10 个，每个版本（A–J）选择一个目标风格；同一首歌的各版本须为不同风格，重复时界面会提示并阻止开始。
- 单首歌曲的“版本数”可改为自己的数量，各版本风格下拉菜单空值代表跟随统一。
- 10 种预设风格：R&B、Lo-fi、Jazz、Acoustic、Remix、Phonk、Hardstyle、Hardtekk、Soul、Funk，也可自定义。“写下具体要求”里每个版本都有独立补充要求。
- 每个版本都是一次完整的 YuE2 生成，版本越多排队越久；第一个版本做原曲分析，其他版本复用。作品页按歌曲分组显示所有版本。

## 使用变调与变速

- **两种方式**：“独立调整”可单独变调（-12 至 +12 个半音）或变速（50%–150%），变速时音高不变；“Slowed / Sped up”像改变唱片转速，音高随速度一起变化，例如 80% 约降 3.9 个半音。
- **混响**：勾选后可调 5–100，适合 Slowed + Reverb 风格；混响保持作品原时长，结尾的混响尾音会淡出。
- **生成前**：在统一设置的“变调与变速”面板设置，或在逐首“单独调整”里改为“单独设置这首歌”。原曲先在本机调整，A / B 两版、旋律与歌词识别都使用调整后的原曲；保留原唱时原唱也一起调整；混响加在生成结果上。速度会改变整首时长，调整后须在 10 分钟以内。
- **已完成作品**：在“我的作品”点“变调 / 变速”，确认后另存为新作品，不重新生成、原作品不变。新作品显示在同一首歌下，可再次调整；它使用独立的本机处理队列，通常几秒完成，不排在 YuE2 任务之后。
- **名称**：调整后的作品在“风格 + 原曲名”后附说明，例如 `Lo-fi Justin Bieber - Baby (Slowed 80%, Reverb 40).wav`。
- 较大的变调或变速可能带来音色失真，请试听复核。本机 FFmpeg 含 Rubber Band 时音质最好；否则自动改用 FFmpeg 的 atempo 方式。

## 使用新的改编控制

- **歌曲类型**：在每首歌旁选择“纯音乐”，A/B 均跳过歌词识别和用于识别歌词的人声提取，向本机 YuE2 发送无演唱要求。已有歌词及演唱偏好保留，切回“有演唱”即可恢复；缺省为有演唱。导入时已有的内嵌歌词只保存在歌曲记录，纯音乐生成不使用它们。
- **纯音乐设置**：禁用保留原唱、演唱性别与音色，仍可调整风格、力度、参考旋律或自由重创。参考模式仍须分析原曲旋律；这与歌词识别是不同步骤。类型修改仅影响后续新任务，不改变已排队任务。
- **作品名称**：展示与下载采用对应 A/B 风格加原曲名；新任务在本机也保存同名 WAV/MP3。已有作品使用新展示和下载名，但不重命名历史文件或重写历史配置。文件名中的系统禁用字符会替换，过长的本机文件名会按路径限制截短；不同生成任务仍保存在各自目录中。
- **A/B 风格选择**：统一设置均为按钮；逐首均为下拉菜单，空值代表跟随对应版本的统一风格。两处都支持自定义，已有逐首名称不会丢失。A/B 须选择不同风格。
- **风格与音色力度**：0–100，默认 75。0 仍按要求生成；100 加强目标风格和声音引导，不是音量控制。
- **参考原曲旋律**：保留识别的乐谱，让模型改编演奏和声音。
- **自由重创**：使用歌词和要求，解除原曲乐谱约束，允许改变旋律、节奏、段落；时长仍为原曲全长。
- **保留原唱**：原录音的人声不变，力度用于伴奏，强制保留参考旋律。
- 支持统一要求、A/B 补充要求，以及逐首力度、旋律和要求。逐首要求替代统一要求，A/B 补充仍会加入。留空要求时各风格使用独立编曲描述。
- 顶部显示版本和更新记录；新作品显示生成时的版本、参数。旧作品标为历史版本，不补造版本号。
- 若看到独立设置提示，可点“全部歌曲跟随统一”，让上方风格和声音选择真正应用到所有列出的歌曲；歌词保留。

声音性别、音色和文字指令由生成模型引导，不能保证每次完全遵从。力度增大可能更慢或出现声音失真；可降到 50–75 再试。自由重创与原曲不再保证同旋律。

纯音乐请求也需试听复核，技术验证不能证明所有输出绝无类人声。参考旋律模式仍依赖本机乐谱转写器，某些输入可能触发其节拍网格错误；本次没有修改或替换模型。

## 源码与本机环境

- `sing-studio-batch-preview/src/`：React 界面。
- `dual-version/`：当前 Python 后端、YuE2 适配、验证和更新脚本（名称沿用之前工作区）。
- `dual-version/release.json`：界面和后端共用的版本来源；`CHANGELOG.md` 保留完整更新记录。
- 现有 Windows 应用依赖外置的本机运行环境；仓库不是附带模型的独立安装包。需要现有 `local-test/ace-env`、FFmpeg、YuE2 GGUF 模型及运行库；原唱保留与换声需要 UVR。Whisper 单独环境的路径参见 `asr-paths.example.json`。换声另需独立环境 `local-test/seed-vc`（Seed-VC，GPL-3.0，以独立程序运行），用 `dual-version/seedvc-download.ps1` 与 `seedvc-install.ps1` 安装，依赖版本见 `seedvc-requirements.txt`。
- 不含歌曲、歌词、模型、生成结果、私有配置或第三方环境，也不自动安装它们。

构建前端：在 `sing-studio-batch-preview/` 使用现有 Node 环境运行 `npm ci`（首次准备依赖）、`npm run build` 和 `npm run test:sites`。构建保留原有 Sites 兼容包装；生产功能必须连接本机 Python 服务，本次不发布云站点。

后端验证：用现有音乐环境的 Python 运行 `dual-version/test_controls.py`、`test_instrumental.py`、`test_adjust.py`、`test_versions.py` 和 `test_voice.py`（纯音乐、变调与换声测试使用 runtime 中的 FFmpeg，先设置 `SING_LOCAL_TEST`；`test_voice.py` 用接口相同的替代引擎，不需要安装 Seed-VC）；运行 `test_backend.py` 前设置 `SING_LOCAL_TEST` 为本机 runtime 目录。变调变速的真实推理验证：`dual-version/benchmark_adjust.py --runtime ... --output <Git 外目录> --validation dual-version/VALIDATION-v1.3.0.json`，可加 `--source <本机纯伴奏 WAV>`；全部通过后才会把该版本验证标记为通过，部署脚本以此为准。后者需要既有示例音频与模型文件来验证可用性，推理本身使用测试进程。换声的真实推理验证：`dual-version/benchmark_voice.py --runtime ... --output <Git 外目录> --source <本机有人声的歌曲> --start <演唱段落秒数> --validation dual-version/VALIDATION-v1.4.0.json`（可加 `--lyrics-file`）。v1.4.0 需要 `benchmark_adjust.py` 与 `benchmark_voice.py` 都写入同一验证文件并通过。真实推理验证另用 `benchmark_controls.py --runtime ... --installed-app ... --output ...`，结果目录须留在 Git 外。

更新现有安装：先完成构建和验证，再使用 `dual-version/deploy-release.ps1 -AppRoot <现有 sing-studio 目录>`。脚本拒绝活动队列，备份应用代码和前端，保留用户数据，并启动原有本机入口。仅用于已安装应用，不创建或下载推理环境；换声引擎由 `seedvc-install.ps1` 单独安装，更新应用不会改动它。

若用户明确授权暂时暂停等待任务，可先暂停队列并等待当前任务结束，再附加 `-AllowPausedQueue` 更新。该开关仍拒绝正在运行的任务及未暂停的等待队列；更新本身保持暂停，核验完成后恢复原暂停状态。不能取消或重写已有等待任务来绕过检查。

新增风格的可复现实测：`dual-version/benchmark_styles.py --runtime <本机 runtime> --output <Git 外的验证目录>`。依次使用同一参考音频、种子、乐谱与 75 力度生成三个 30 秒结果，核对实际请求、回放、时长和导出；该结果不代表主观听感通过。

## 以后每次更新

更新 `release.json` 和前端 package / lock 版本、追加 `CHANGELOG.md`、记录验证和 handoff，然后提交并打 `vX.Y.Z` 标签。新增兼容功能增加次版本，修复增加修订号，破坏性变更增加主版本。不要复用或覆盖已经推送的版本标签。

力度当前映射为语义 CFG `1 + 0.008 × 力度`，范围 1.0–1.8；CFG 同时影响风格、声音及歌词条件，不是独立的人声音色转换器。自由模式发送 `cot=off, abc=""`，参考模式发送 `cot=melody` 及完整参考谱；不复用成品或语义 token。

协议参考：[yue2.cpp 架构与请求字段](https://github.com/ServeurpersoCom/yue2.cpp/blob/master/docs/ARCHITECTURE.md)、[YuE 官方生成与翻唱说明](https://github.com/multimodal-art-projection/YuE/blob/main/skills/yue2-music/references/generation-and-covers.md)。以当前安装运行库的实际验证为准。
